# x86_64-openbsd-sysroot

OpenBSD 8.0 base system sysroot for x86_64-openbsd (amd64): headers, crt objects, libraries and libc++'s std module sources

Assembled from the official base80.tgz and comp80.tgz sets (cdn.openbsd.org), checked against the release's signed SHA256.

Packaged for xlings by the recipe `pkgs/*/x86_64-openbsd-sysroot.lua` of
[openxlings/xim-pkgindex](https://github.com/openxlings/xim-pkgindex), whose
`.agents/tools/` holds the script that assembled it. Each release's
`PROVENANCE.md` (inside the archive) states the upstream files, their digests and every change.
